# Restaurant Order and Service Simulation

## Project Overview
This project simulates a restaurant's order and service process using Python. It models customer arrivals, order processing, kitchen preparation, and serving operations.

## Objectives
- Simulate customer arrivals.
- Analyze waiting times at different service stages.
- Identify bottlenecks in restaurant operations.
- Compare different staffing scenarios.
- Improve service efficiency.

## Technologies Used
- Python
- SimPy
- Pandas
- Matplotlib
- Gradio
- Google Colab

## Features
- Customer arrival simulation
- Multiple service counters
- Kitchen and serving staff management
- Waiting time analysis
- Scenario comparison
- Interactive simulation dashboard

## How to Run
1. Open the notebook in Google Colab.
2. Install the required libraries.
3. Run all notebook cells.
4. Explore the simulation results.
